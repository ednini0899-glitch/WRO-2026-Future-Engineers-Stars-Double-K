# Engineering Journal

## Stars Double K – WRO 2026 Future Engineers

This engineering journal documents the design, construction, programming, testing, failures, improvements and technical decisions made during the development of our autonomous vehicle.

The objective of this document is to show the complete engineering process followed by Stars Double K, including successful tests and problems encountered during development.

## Development Process

Our development methodology follows an iterative process:

Problem → Idea → Prototype → Test → Result → Improvement → New Test

Each important modification to the mechanical design, sensors or software will be documented in this journal.

## Current Robot Configuration

- LEGO Education SPIKE Prime Hub
- Port A: Traction motor
- Port E: Steering motor
- Port B: Distance sensor
- Port F: Color sensor

## Current Development

The team is currently testing:

- Vehicle traction
- Mechanical steering
- Steering calibration
- Distance detection
- Red obstacle detection
- Green obstacle detection
- Autonomous obstacle avoidance

Additional tests and results will be added as development continues.
